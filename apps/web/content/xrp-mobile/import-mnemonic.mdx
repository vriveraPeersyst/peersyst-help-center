You already have an XRP wallet somewhere else. Here is how to bring it into XRP Mobile, with the same address and the same balance.

<video controls preload="metadata" poster="/help/xrp-mobile/import-mnemonic/poster.jpg" src="/help/xrp-mobile/import-mnemonic/video.mp4"></video>

Prefer to read? The steps below are the same walkthrough, 5 screens and 33 seconds of video.

## 1. Tap Import wallet

![Tap Import wallet](/help/xrp-mobile/import-mnemonic/step-1.png)

From the welcome screen, tap Import wallet instead of creating one.

## 2. Choose recovery phrase

![Choose recovery phrase](/help/xrp-mobile/import-mnemonic/step-2.png)

Pick recovery phrase. That is the 12 words almost every wallet gives you when you first set it up.

## 3. One word per box

![One word per box](/help/xrp-mobile/import-mnemonic/step-3.png)

Type your words in order, one per box. There is a paste button if you keep them in a password manager, and the app checks the phrase is valid before it lets you continue.

## 4. Name it and set a PIN

![Name it and set a PIN](/help/xrp-mobile/import-mnemonic/step-4.png)

Give it a name and set a PIN for this device. The PIN is local: it protects the app on this phone, it is not part of your wallet.

## 5. Same wallet, new phone

![Same wallet, new phone](/help/xrp-mobile/import-mnemonic/step-5.png)

And there it is. Same address, same balance, and the keys never left your hands.
