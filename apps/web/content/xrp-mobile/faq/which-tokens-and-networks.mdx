- **XRP** lives natively in your XRP Ledger account. Tokens issued on the XRP Ledger itself (IOUs, NFTs, MPTs) are not supported yet; see [Which XRP Ledger features are supported?](/docs/xrp-mobile/faq/which-xrpl-features-are-supported).
- **Everything else** (Bitcoin, Ether, USDC, USDT, Solana and dozens more, each on its supported networks) is handled through the intents layer. The list you see in Receive and Swap is the live list of what that layer supports right now.

Some things are not available yet: Monero, shielded Zcash addresses, and any token that the intents network has not listed. Requests for new assets go to that network; we pass them on but do not decide them.

Always pick the asset **and** the network in Receive before copying an address: the same token on a different network needs a different address.
