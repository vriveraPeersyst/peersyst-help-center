## Before anything else

The campaign needs an **activated** XRP Ledger account: the referred wallet must have received its first 1 XRP. A code applied to a wallet that has never been funded counts only once that wallet is active. See [The app says my account needs activating](./account-not-activated).

## The code says invalid

- Codes are case-insensitive but must be complete. Check for missing characters.
- You cannot use your own code, and a wallet can redeem one code only.
- The **Apply code** button lights up before the input is fully valid, and some unexpected failures are reported as "invalid code". Wait a moment and try once more before assuming the code is wrong.

## Applying a code takes very long

Redemption can take up to a minute while it is verified. Keep the app open. If the sheet freezes after tapping **Follow to verify**, close the sheet and verify the follow from the task card on the Share tab instead.

## The follow is not verified

Follow verification checks that your X account follows the campaign account, and it is not instant. Make sure the handle you typed is exactly your X handle, without the @, and that the follow is public. Give it a few minutes and reopen the Share tab.

## Points or rank look wrong

Points update when a task is verified, not when you complete it, and when tied on points the card and the leaderboard can currently show different ranks. That is a display issue being fixed; the points themselves are right.

## When to contact support

If a code is refused with a wallet that is active, or a verified task has not credited after a day, contact support with the details at the top of this page. The team can see the campaign record for your address.
